# Конвенции — правила реализации

> Правила уровня code review, нарушение которых не требует ADR (инварианты — `QUICK_REF §Границы`).
> Каждое выведено из прецедента проекта, и прецедент остаётся в записи: правило без происхождения
> нельзя ни проверить, ни оспорить. Подробные разборы — в ADR и git log.
>
> **Когда заводится `C-NN`** — по одобрению владельца, все условия: приём или дефект встречен в
> **двух независимых местах** либо однажды дорого; применим шире одного файла; названо последствие
> нарушения; не держится тестом, типом, схемой или линтером (держится — здесь только ссылка на
> механизм). Длительность отладки основанием не является. ID — `C-NN`, не переиспользуется.

---

*Записи — в `##`-секциях по темам («Данные на границе», «Ловушки библиотек», …), не по номерам.
Секция заводится, когда во второй раз некуда положить запись.*
