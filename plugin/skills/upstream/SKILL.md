# Улучшение из проекта — в кит

1. Сформулировать: что меняется, в каком файле кита (`template/` — файлы проекта, `plugin/` — роли и скиллы), почему, на каком прецеденте; проектное отделить. Без одобрения владельца — только `propose_new` в финале.
2. Получить кит и ветку:

```bash
KIT="${CLAUDE_PLUGIN_DATA}/kit"   # не подставилось — временный каталог; нужен полный клон
if [ -d "$KIT/.git" ]; then git -C "$KIT" fetch -q origin && git -C "$KIT" checkout -q --detach origin/main; else git clone -q https://github.com/xkdg/agent-wiki-template "$KIT"; fi
```

```bash
git -C "$KIT" checkout -b "upstream/<короткое-имя>"
```

3. Выполнить `$KIT/kit/INSTALL.md §upstream` с п. 4: хирургическая правка, `CHANGELOG.md`, `kit/VERSION`, `claude plugin validate`, PR. В `main` — только по явному слову владельца.
4. После слияния роли и скиллы обновятся сами; в проекте — `/agent-wiki:sync`, конфликт по этому файлу уйдёт.
