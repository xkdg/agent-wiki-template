# CLAUDE.md — репозиторий кита agent-wiki-template

Это не проект с вики, а сам кит. Протокол, который получают проекты, — `template/CLAUDE.md`; здесь — правила работы с китом.

- **Источник правды — живые проекты.** Изменение без прецедента в проекте не вносится (`kit/INSTALL.md §upstream`).
- **Что где:** файлы проекта — `template/` (состав и тип core/seed — `kit/MANIFEST`); роли и скиллы — `plugin/`; процедуры для агентов — `kit/INSTALL.md`; скрипт — `kit/kit.py`.
- **Каждое изменение:** запись в `CHANGELOG.md`; `kit/VERSION` — patch (формулировки), minor (новое правило, роль, скилл), major (структура, требующая миграции проектов — с инструкцией в CHANGELOG).
- **Ядро ссылается на заготовки по секциям** (`INDEX.md §Области ADR`, `§Проектные маршруты`, `QUICK_REF §Границы`). Переименовал секцию заготовки — это major: в проектах она уже названа по-старому.
- **`plugin.json` без `version`:** плагин версионируется коммитом, поэтому любой push в `main` доезжает до всех установок. Не добавлять `version`, иначе обновление пойдёт только по ручному бампу.
- **Проверка перед коммитом:** `claude plugin validate .` (манифест маркетплейса и плагина) и прогон `kit/kit.py` init → sync на временном проекте, если менялись `template/`, `kit/MANIFEST` или скрипт. Плагин локально без установки — `claude --plugin-dir plugin`.
- **Не коммитить в `main` без слова владельца** — ветка и PR.
