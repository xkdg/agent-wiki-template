# Agent Wiki Template

Протокол агента и вики проекта для Claude Code. Агент знает, что читать перед задачей, как собрать требования, кому из субагентов что поручить и что делать с документацией после задачи. Ставится один раз на аккаунт, разворачивается в любой проект одной командой, обновляется во всех проектах из одного репозитория.

## Что входит

**Плагин `agent-wiki`** — ставится на аккаунт, обновляется сам по каждому коммиту в этот репозиторий.

| Скилл | Что делает |
|---|---|
| `/agent-wiki:brief` | Бриф фичи: размер задачи → вопросы владельцу по одному, с рекомендацией → критерии приёмки → ТЗ-файл. До одобрения — ни строчки кода |
| `/agent-wiki:init` | Развернуть протокол и вики в проекте |
| `/agent-wiki:sync` | Обновить протокол в проекте до свежей версии, не трогая проектную вики |
| `/agent-wiki:upstream` | Отправить улучшение из проекта в этот репозиторий — оно доедет до всех проектов |

| Роль субагента | Что делает |
|---|---|
| `scout` | разведка кода: точки входа, вызывающие, связанные ADR и инварианты — с якорями `путь:строка` |
| `implementer` | реализация по готовой спецификации; не коммитит, необратимое не делает |
| `reviewer` | ревью в свежем контексте: задача, инварианты, тихие отказы; вердикт без правок |
| `verifier` | приёмка на реальных данных против baseline, PASS/FAIL по каждому критерию |
| `investigator` | отладка: сначала измерения, потом гипотезы; исправление — предложением |
| `doc-auditor` | сверка вики и README с кодом: пути, константы, номера ADR, ссылки |

Скиллы и роли живут в плагине, а не в проекте, — поэтому в папке `wiki/` проекта их нет.

**Файлы проекта** — кладутся в репозиторий проекта командой `init`:

```
CLAUDE.md                 протокол агента; подгружает INDEX, RULES, QUICK_REF в каждую сессию
wiki/
├── RULES.md              когда предлагать ADR, C-NN, скилл; что делать после задачи
├── INDEX.md              что за проект, куда идти за чем, карта кода
├── context/
│   ├── QUICK_REF.md      инварианты, пороги, контракты, договорённости проекта
│   ├── PRODUCT.md        продукт, процессы, интеграции, данные — схемами
│   └── CONVENTIONS.md    правила реализации с прецедентом (C-NN)
├── adr/_TEMPLATE.md      шаблон решения
├── todo/_TEMPLATE.md     шаблон ТЗ
├── todo/BACKLOG.md       намерения
└── .kit-version          версия кита в проекте
```

`CLAUDE.md`, `RULES.md` и шаблоны — **ядро**: одинаковы во всех проектах, обновляются `sync`, в проекте не правятся. Остальное — **заготовки**: создаются один раз и дальше принадлежат проекту.

## Установка

**Через claude.ai — на все устройства.** Customize → Plugins → добавить маркетплейс `xkdg/agent-wiki-template` → установить `agent-wiki`. Плагин появится в Claude Code на всех машинах и в облачных сессиях; автообновление включено.

**Или только на эту машину** — в Claude Code:

```
/plugin marketplace add xkdg/agent-wiki-template
/plugin install agent-wiki@agent-wiki-template
```

Автообновление здесь выключено по умолчанию: `/plugin` → Marketplaces → `agent-wiki-template` → Enable auto-update.

Нужны `git` и Python 3.8+ (для `init` и `sync`).

## Развернуть в проекте

В корне проекта, в Claude Code:

```
/agent-wiki:init
```

Агент склонирует кит, создаст файлы и предложит вместе заполнить `INDEX` и `QUICK_REF §Границы`. Протокол подхватится в следующей сессии или после `/clear`.

- **Без плагина** — сказать любому агенту: «Разверни xkdg/agent-wiki-template в этом проекте». Он следует `kit/INSTALL.md`.
- **С телефона** — создать репозиторий на GitHub, открыть по нему облачную сессию Claude Code и сказать то же.
- **Проект на старом шаблоне** (есть `CLAUDE.md` и `wiki/`, нет `wiki/.kit-version`) — `/agent-wiki:init` предложит миграцию по `kit/INSTALL.md §Миграция`.

## Использование

| Ситуация | Что делать |
|---|---|
| Новая фича или нечёткая задача | `/agent-wiki:brief` или просто «хочу добавить…» — скилл срабатывает сам |
| Обычная задача | ничего: агент читает вики, после задачи называет `documentation_action` |
| Нужна разведка, ревью, приёмка, отладка | агент поручит роли сам; можно попросить явно: «отдай reviewer» |
| Вышла новая версия кита | `/agent-wiki:sync` в проекте |
| В проекте нашлось улучшение для всех | одобрить предложение агента → `/agent-wiki:upstream` |

Личные правила для всех проектов (как давать команды, язык ответов) — в `~/.claude/CLAUDE.md`, не в кит.

## Обновления

- **Роли и скиллы** обновляются сами: плагин версионируется коммитом.
- **Файлы проекта** — `/agent-wiki:sync`. Файл ядра, который правили в проекте, не перезаписывается: агент покажет diff и спросит — перенести правку в `QUICK_REF`, отправить в кит или взять версию кита.
- Что изменилось — `CHANGELOG.md`; версия — `kit/VERSION`.

## Репозиторий

```
template/       файлы, которые попадают в проект (состав — kit/MANIFEST)
plugin/         плагин agent-wiki: agents/ — роли, skills/ — скиллы
kit/            kit.py (init | sync | status | take | stamp), MANIFEST, INSTALL.md, VERSION
.claude-plugin/ манифест маркетплейса
CHANGELOG.md
```

Правила изменения кита — `CLAUDE.md` в корне этого репозитория.
