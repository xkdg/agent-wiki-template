# Конвенции — правила реализации

> Короткие правила общего вида; каждое выведено из реального прецедента проекта, и прецедент
> остаётся в записи одной строкой: правило без происхождения нельзя ни проверить, ни оспорить.
> Наполняется из разбора дефектов, чей урок переиспользуем; подробные разборы — в ADR по ссылкам
> и в git history этого файла. Системные инварианты и границы живут не здесь, а в
> `QUICK_REF.md §Границы`; здесь — правила уровня code review, нарушение которых не требует ADR.
>
> **Нумерация:** ID формата `C-NN`, sequential, **никогда не переиспользуется**; в заголовке
> полный ID; ссылка на соседнюю запись — по ID и в том месте текста, где без неё теряется контекст.
>
> **Когда заводится запись.** По одобрению владельца: агент предлагает, не создаёт. Основание —
> приём или дефект, встреченный в **двух независимых местах**, либо один случай с высокой ценой;
> единичный локальный прецедент конвенцией не становится. Прежде текстового правила проверяется,
> не держится ли оно тестом, типом, схемой или линтером: держится — место правила там, а здесь
> остаётся ссылка на механизм. Правило обязано быть применимо шире одного файла и называть
> последствие нарушения. **Длительность отладки основанием не является:** долгий разбор частного
> бага правила не порождает, короткий разбор дважды встреченного — порождает.

---

*Записи группируются `##`-секциями по темам («Данные на границе», «Контракт с внешней системой»,
«Ловушки библиотек», …), а не по номерам: номер — идентификатор, не порядок чтения. Секции
заводятся по факту, когда во второй раз некуда положить запись.*

## <Тема>

### C-01: <Правило одной строкой, императив — что делаем, а не что запрещено>

*1–3 предложения: что именно делается и на какой границе применяется. Формулировка проверяемая:
из неё видно, нарушено правило или нет. Короткий пример кода — только если словами дороже.*

**Прецедент:** *откуда правило взялось: что сломалось, где, чем это стоило. Конкретно — файл,
дата, число: «выгрузка 2026-07-20 хранила идентификаторы числами, 12 записей потеряли ведущий
ноль». Без прецедента запись не заводится.*
