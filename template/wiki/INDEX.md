## Карта кода — роль читается из пути

*Опционально, окупается быстро: дерево с назначением каждой директории — чтобы из пути читались роль модуля и направление зависимостей.*

```
<пакет>/
├── <точки входа>       ← пути команд неизменны
├── core/               ← основание: конфиг, БД, события — не знает ни о ком
├── <sources|adapters>/ ← внешние данные
└── <domain>/           ← прикладная логика
```

*Направление импортов важно — держать его тестом (обход AST), а не обещанием, и назвать тест здесь.*

*Подсистемы — отображение понятий на файлы, которого не даёт файловая система. Строка правится, только когда появилась подсистема или сменился её канонический источник.*

| Подсистема | Куда идти |
|---|---|
| *например, скоринг* | *`adr/0007-….md`, `QUICK_REF §Формулы`, `<путь к коду>`* |
| *например, анти-бан* | *`C-12`, `<путь к коду>`* |
