## Амортизация после done

*`done` и приёмка подтверждена (прод-задача — на проде) → файл амортизируется и удаляется:*

- [ ] *Изменившиеся числа, пороги, контракты → `QUICK_REF`; процессы и данные → `PRODUCT` (`update_existing`, без согласования)*
- [ ] *Решения, на которые будут ссылаться, — в одобренном ADR, самодостаточно. Не одобрен — решение живёт в коде и git log, это законный исход*
- [ ] *Переиспользуемый приём, отклонённое из скоупа, открытые вопросы — предложением в финале, не записью в `CONVENTIONS` и `BACKLOG`*
- [ ] *Входящие ссылки (grep по имени в вики и коде) → на долгоживущие артефакты*
- [ ] *Файл удалён; след — git log*

*Исключение — ТЗ с самостоятельной ролью (например, источник данных генератора): не удаляется, помечается постоянным в `INDEX.md`.*
