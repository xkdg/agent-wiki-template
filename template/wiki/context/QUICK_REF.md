# Quick Reference — оперативные факты

> Факты, нужные на каждой задаче. **Тест на попадание:** без факта агент либо выведет его из кода
> заново, потратив контекст, либо молча нарушит. Здесь «что», а не «почему»: обоснования — ADR,
> правила реализации — `CONVENTIONS`, процессы — `PRODUCT`, история замеров — git log.
>
> Обязательна только `§Границы`, остальное проект выращивает сам: константы и пороги («значение ·
> где в коде · какой ADR»), state machine (единственный источник правды), контракты данных и
> канонические форматы, стадии и команды запуска, договорённости проекта (прод-доступ, что агент
> делает сам, что — с подтверждением). Пустые секции удалять, «TBD» не оставлять.

---

## Границы (нарушение = сначала ADR)

*Единственный дом системных запретов: инварианты и операционные перечни к ним (что не уходит во
внешний вызов, что запрещено в логах). Из пункта видно, чем он держится — тестом, типом, топологией
кода или только этой строкой. Изменение пункта — повод предложить ADR.*

1. *Сервисы не импортируют друг друга — только общую библиотеку*
2. *PII не покидает процесс: в LLM и логи не попадают `<id>`, дата рождения, координаты*
3. *Миграции БД — только через централизованный механизм, не из кода сервисов*
